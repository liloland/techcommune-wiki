# Contributing to the TechCommune wiki

Thank you for helping. Every page is a Markdown file in the `content/` folder, and every change comes in as a pull request that the maintainer reviews before anything is published.

**The full guide is the wiki page [How to add or improve a page](content/how-to-contribute.md)**, and the rules are in [Wiki rules](content/wiki-rules.md). In short:

1. Search the wiki and the main site first: add to an existing page if the topic is covered.
2. Copy the format of an existing page (a short settings block, then the text).
3. Tell us what you tested the commands on. No secrets, no real people's names, no copied text.
4. Open a pull request. An automatic check validates the page and tells you what to fix.

Changes to `tools/`, `templates/`, `wiki.toml` or `.github/` are code changes. Please open an issue first so we can talk about them.
